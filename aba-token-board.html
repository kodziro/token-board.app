ABA token board online: run a token board in your browser

By Natalia Jakubczyk-Gajewska · Last updated: October 19, 2026

An ABA token board is a visual reinforcement system: the learner earns a token for each target behavior and trades a full board for a reward chosen in advance. The free board on this site runs in any browser, on the therapist's laptop, a tablet or a shared screen. Nothing is uploaded and no account is needed.

What is a token board in ABA?

A token board is a token economy made visible: a row of empty slots, one token for each correct response or target behavior, and a backup reinforcer when the board is full. Tokens are conditioned reinforcers; they work because they are reliably exchanged for something the child wants. A systematic review describes token economies as well-established and widely used in behavior analysis, and a review of token economy research in children with autism and intellectual disability found them effective across many settings. Reinforcement itself is listed by AFIRM at UNC as an evidence-based practice for autistic learners.

When does a BCBA or RBT use a token board?

A token board is used when a learner needs reinforcement more often than the natural reward can be delivered. Typical cases: discrete trial teaching (one token per correct trial), a work period too long for a single reward, and transitions. The BCBA sets the target behavior, exchange rate and reinforcer in the plan; the RBT runs the board in session.

How do I run a session with the free web board?

  1. Pick the reinforcer first. Open ⚙, choose a reward the child wants today, and show it before the first trial.
  2. Choose the number of tokens. 3 or 5 slots for a new learner, 10 for a longer work period.
  3. Give a token for the target behavior. Tap a slot right after the behavior; the token pops in with a short tone. Tap a filled slot to remove it if you made a mistake.
  4. Exchange. When the last slot fills, the board celebrates and the child gets the reward. "Hooray!" clears the tokens for the next round.

Two habits that keep the board working

  • Keep the exchange immediate at first; stretch the ratio only after the child earns reliably.
  • Keep your data sheet: the board is the learner's view, not the record.

Quick answers

Do I need an account to use the online token board?

No. The board opens in the browser, needs no login, and saves the title, icon, reward and tokens on that device only.

Can I use the online token board for discrete trial teaching?

Yes. Tap a slot after each correct trial; with 5 or 10 slots the learner trades a full board for the reinforcer chosen before the first trial.
